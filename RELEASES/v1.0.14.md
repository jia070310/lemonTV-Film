# v1.0.14 (10014)

**发布日期：** 2026-10-06

## 概述

本版本支持配置多个 MacCMS 源并自动切换；电视端可用扫码打开局域网管理页。隐私规则按每个源单独保存。首页「最新推荐」改回采集接口 `level=9` 拉取，避免网页筛选页漏条。

## 新功能与改进

- **多源管理**：服务器可填写名称，列表支持测试 / 使用 / 删除（删除需确认）
- **当前源不通时自动切换**到已保存的其他源
- **局域网管理**：电视端扫码后可用手机或电脑配置资源与隐私（UTF-8 中文名称）
- **按源隐私**：敏感关键词与隐藏分类保存在所选服务器上，不串源
- **启动图**：使用 nodpi 原图，避免放大发糊
- **最新推荐**：优先 `ac=list&level=9` / videolist，网页 `/vod/show/level/9.html` 只作补漏

## 安装升级

1. 下载 `LomenTV-release-v1.0.14.apk`
2. 在电视 / 盒子上覆盖安装（数据与设置保留）
3. 若内置更新检测失败，可手动从 [Releases](https://github.com/jia070310/lemonTV-Film/releases) 下载安装

## 系统要求

- Android 5.0（API 21）及以上
- 可访问所配置的 MacCMS 站点

## 构建命令

```bash
./gradlew :app:assembleRelease
```

输出：`app/build/outputs/apk/release/LomenTV-release-v1.0.14.apk`
